# 褒められアプリ(仮)要件定義書 v0.1

作成日: 2026-08-19
フェーズ: MVP要件定義
実装形態: Web優先 → 将来スマホアプリ

---

## 1. 背景と課題

頑張ったことを誰にも褒めてもらえない、あるいは自分で認めてあげられない瞬間がある。
本物のSNSに投稿すれば承認は得られるかもしれないが、評価される怖さが先に立つ。
「褒められる」という報酬だけを、リスクなく安全に得たい。

### ターゲット

- 自己評価が厳しく、頑張りを自分で肯定できない人
- 承認欲求はあるが、本物のSNSに晒すのは怖い人
- フリーランス・学生など、日々の頑張りを見てくれる身近な人がいない人

---

## 2. コアループ

1. やったことを一言入力する
2. 演出パターン(疑似SNS)を選ぶ、または発火させる
3. 音+アニメーションで反応が積み上がっていく
4. スクショしたくなる画面が残る → 共有 → 拡散

---

## 3. 演出パターン仕様(MVP)

三本柱は **LINE型 / X型 / Instagram型**。

**方針**: 実物のUIレイアウト・インタラクション・配色は忠実に再現する。
ただし **ロゴマーク・サービス名・アプリアイコンの3点のみ独自意匠**にする(商標リスクの回避)。

### 3-1. タイムライン風(X型) 【MVP・Phase 0】

| 項目 | 内容 |
|---|---|
| 入力 | 一言をポストとして投稿 |
| 反応 | いいね・リポスト・リプライ数がカウントアップ演出で増加 |
| 演出 | 数字のインクリメントアニメーション、ハートが弾ける、通知が積み上がる |
| 上限 | MVPは固定シナリオ(数値レンジ・伸び方をあらかじめ設計)。AI生成リプライは後回し |

→ 詳細は [02_X型演出_実装仕様.md](02_X型演出_実装仕様.md)

### 3-2. グループトーク風(LINE型) 【MVP・Phase 1】

| 項目 | 内容 |
|---|---|
| 入力 | 一言テキストをグループトークに自分の発言として投稿 |
| 反応 | 登録した複数の「友達」人格が時間差で既読・スタンプ・褒めコメントを返す |
| 演出 | 吹き出しが一つずつポップイン、既読数が増える、通知音 |
| 人格 | MVPでは固定3〜4体(テンション高い友達／ノリの良い後輩 等) |

### 3-3. ストーリーズ風(Instagram型) 【MVP・Phase 1】

| 項目 | 内容 |
|---|---|
| 入力 | 一言をストーリーズ風の1枚に投稿 |
| 反応 | 閲覧者リストが増え、ハートが画面下から飛んでいく演出 |
| 演出 | ストーリーズ特有のプログレスバー、ハートの連続タップ風アニメ |

### 3-4. 先生風・採点演出 【後回し】

花丸・採点コメントで褒める単体演出。SNS3種の実装後に検討。

---

## 4. MVPスコープ

| 項目 | 残す(MVP) | 後回し |
|---|---|---|
| 演出パターン | LINE / X / Instagram 型 計3種 | 先生風・友達単体チャット等の追加 |
| キャラクター | 各演出に紐づく固定人格(数体) | キャラのカスタマイズ・追加購入 |
| 共有 | スクショ前提の映える画面 | 実SNSへのワンタップ投稿連携 |
| 履歴 | 直近の演出のみ表示 | 投稿履歴の蓄積・カレンダー |
| 音 | 演出ごとに専用の報酬音(3〜5種) | BGM・音のカスタマイズ |

## 5. 非機能要件

### 著作権・商標への配慮

実プラットフォームの **ロゴ・アプリアイコン・サービス名** は使用しない。
UIの「構造」「操作感」「配色」の踏襲は許容範囲とする。
公開直前に一度リーガルチェック(簡易でも)を挟む。

### その他

- **対応デバイス** — スマホブラウザ最優先(共有導線がスマホ前提のため)、PCは閲覧できれば十分
- **パフォーマンス** — 演出発火から初回反応まで1秒以内。音アセットは軽量に
- **アカウント** — MVPはログイン不要(その場で遊べる)
- **データ保存** — MVPでは入力履歴をサーバー保存しない(プライバシー配慮・実装コスト削減)

---

## 6. 収益化方針

MVPは **完全無料・広告なし**。バズ検証とスクショ拡散を最優先し、収益導線は入れない。

将来的な収益化候補(未決定):

- 演出パターンの追加パック課金(コンテンツ単位)
- キャラクターボイス・限定演出のプレミアム提供
- 広告は最終手段。体験の気持ちよさを損なわない範囲でのみ検討

## 7. ロードマップ

| フェーズ | 内容 |
|---|---|
| Phase 0 | Web MVP。X型演出1本を作り切る。最速でバズ検証 |
| Phase 1 | LINE / Instagram 型を追加し、3種を選択できるようにする |
| Phase 2 | ユーザーがついたらスマホアプリ化を検討。通知・履歴などリテンション機能 |
